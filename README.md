# Horoscope App

## Technologies Used
- **React**: For building the user interface and managing component-based architecture.
- **Sass (SCSS)**: For advanced and modular styling.
- **JavaScript**: For logic and interactivity.
- **HTML5 & CSS3**: For structure and basic styling.

## What I Learned
Through this project, I learned how to:
- Structure a React application with reusable components.
- Use SCSS for more maintainable and scalable styles.
- Manage state and props in React.
- Organize project files and follow best practices.
- Improve the user experience with responsive design.
